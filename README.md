# Course Management System

**Course:** CS300 – Data Structures and Algorithms: Analysis and Design  
**University:** Southern New Hampshire University

---

## Overview

This project was completed for CS300 – Data Structures and Algorithms: Analysis and Design at Southern New Hampshire University.

The application manages university course information by reading course data from a file, organizing it using appropriate data structures, and allowing users to efficiently search, retrieve, and display course information. The project emphasizes algorithm efficiency, scalability, and clean software design.

---

## Features

- Import course information from a data file
- Store course data using efficient data structures
- Search for courses by course number
- Display all courses in alphanumeric order
- View course prerequisite information
- Compare data structure performance
